A Simple mindsweeper game to experiment with raylib's libraries and functions.
The main idea and some amount of the code came from a video named "Making Minesweeper in Raylib with C"
by Andrew Hamel Codes (video link: https://www.youtube.com/watch?v=3-EYrPRdjp4&t=3097s).
The most important parts are explained with comments in the source code.
